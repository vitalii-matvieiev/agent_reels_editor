# Reels Agent

**Твій AI-монтажер вертикальних відео.** Кидаєш сире відео з телефону —
отримуєш готовий рілс: паузи вирізані, субтитри по словах, хук стоїть там,
де його не зріже стрічка.

Працює в **Claude Code**, **OpenAI Codex** і **Google Antigravity**.

Зібрав [**Віталій Матвєєв**](https://www.instagram.com/matvieiev.vitaliy) —
підприємець і ментор. Це той самий пайплайн, яким змонтовані рілси на його
сторінці, з усіма помилками, за які вже заплачено охопленням.

---

## Що він робить

| | |
|---|---|
| **Питає про твій стиль** | Кольори, шрифт, лого, темп. Один раз — далі пам'ятає |
| **Розбирає твій референс** | Даєш рілс, яким задоволений — агент знімає з нього цифри |
| **Розшифровує мову** | Whisper локально, з мітками по кожному слову |
| **Вирізає затики** | Ріже паузи по мітках слів, а не на слух. Жодне слово не обрізане |
| **Робить субтитри** | По 3 слова, активне підсвічене. Не лізуть на обличчя |
| **Ставить хук у безпечну зону** | Головне. Нижче — чому |
| **Показує до рендеру** | Прев'ю кадрів і плитки профілю. Правиш до фіналу, не після |
| **Вчиться на результатах** | Кажеш покази — агент міняє налаштування під те, що працює в тебе |

**Він не публікує.** Віддає файл, далі ти сам.

## Чому хук — це головне

Один із рілсів, на якому будувався цей плагін, зібрав **96 показів**. Сусідні
пости за той самий тиждень — **1029** і **1183**.

Монтаж був чистий, субтитри правильні, звук рівний. Провалився хук: плашка
стояла вгорі кадру, а сітка профілю ріже по **240 px зверху й знизу** від
кадру 1080×1920. Людина бачила обрізаний текст без початку.

Тому агент:

- ставить текст тільки в зону **y 480…1350**
- відмовляється рендерити, якщо текст із неї вилазить
- показує `grid_preview.png` — справжній кроп 3:4, як у профілі
- вимагає, щоб хук був **заявою**, а не підписом

> ❌ «Claude Code монтує мої Reels» — підпис, нічого не обіцяє
> ✅ «Монтаж коштував $10. Агент робить за 3 хвилини» — заява, з якою можна посперечатись

Заміри й математика — у [`skills/matvieiev-agent_reels-editor/references/safe-zones.md`](skills/matvieiev-agent_reels-editor/references/safe-zones.md).

## Встановлення

**Термінал відкривати не треба.** Усе робить сам агент.

### 1. Постав Claude Code

Завантаж з [claude.com/code](https://claude.com/code), встанови як звичайну
програму, увійди в акаунт. Потрібна підписка — приблизно $20/міс.

Плагін також працює в OpenAI Codex і Google Antigravity.

### 2. Завантаж і розпакуй плагін

Архів зі сторінки <https://www.matvieiev.com/agents/reels-editor> —
двічі клікни по завантаженому файлу, він розпакується сам.

Або через git:

```bash
git clone https://github.com/vitalii-matvieiev/agent_reels_editor.git
```

### 3. Відкрий папку в Claude Code і напиши «привіт»

Далі агент зробить усе сам:

- перевірить, чого бракує на машині
- поставить, що потрібно — **без пароля, не чіпаючи систему**
- зареєструє себе як навичку, щоб працювати з будь-якої папки
- запитає про твій стиль: кольори, шрифт, темп

Усе, що ставиться, лягає всередину папки плагіна. Видалиш папку — не лишиться
нічого.

### Якщо ставиш вручну

```bash
python3 setup.py     # ffmpeg, Python, залежності
./install.sh         # зареєструвати навичку
```

`setup.py --check` показує стан, нічого не змінюючи.

визначить це сам. Результат той самий.

## Точність проти швидкості

За замовчуванням стоїть **найточніша модель** розшифровки — `large-v3`. Вона
найкраще чує імена, бренди й назви, а це найдорожчі помилки: неправильне ім'я
в анонсі помічають усі.

Платиш за це часом — приблизно **17 хвилин на кожну хвилину відео** на
звичайному процесорі. Агент скаже точну оцінку перед запуском і сам
запропонує альтернативу:

| Модель | Хвилина відео | Чим платиш |
|---|---|---|
| `large-v3` (за замовчуванням) | ~17 хв | нічим — еталон |
| `medium` | ~6 хв | іноді плутає імена й рідкі слова |
| `small` | ~3 хв | помітно більше помилок у назвах |
| `base` | ~1.5 хв | лише для чернетки |

Хочеш швидше — просто скажи агенту, він перемкне і запам'ятає вибір. Або
вручну:

```bash
python transcribe.py audio.wav transcript.json --model medium
```

Агент ніколи не знизить точність мовчки — тільки після твого слова.

## Якщо потрібна генерація

Цей плагін монтує те, що **ти вже зняв**. Він не вміє малювати кадри з нуля —
і не намагається.

Якщо потрібно саме створити відео там, де знімати нічого, є інший інструмент:
**[OpenMontage](https://github.com/calesthio/OpenMontage)** від
[calesthio](https://github.com/calesthio). Генерує кадри, фони, анімацію,
озвучку; 12 пайплайнів від пояснювальних роликів до трейлерів.

Це чужий проєкт, не мій — я ним користуюсь. Ліцензія AGPLv3, потрібні ключі
до платних сервісів:

| | Ціна |
|---|---|
| Картинка | від **$0.02** — FLUX, Imagen, Recraft |
| Відео | від **$0.05/сек** (WAN), Kling — $0.07, Veo 3 — $0.40 |
| Озвучка | Google: перший **1 млн символів/міс** безкоштовно |

Хвилина повністю згенерованої анімації — $1.50–4. Ролик із кількома
вставками — $0.15–1.50.

Вони не конкурують: цей — щоб довести до пуття власну зйомку, той — щоб
зробити відео з нічого.

### Поставити обидва

```bash
python3 setup.py --pro
```

Завантажує OpenMontage у `pro/` разом із Node і Remotion (~900 МБ) і підключає
його як додаткові можливості. OpenMontage не вшитий в архів — він тягнеться з
власного репозиторію, тому цей плагін лишається під MIT.

## Як він стає кращим

Після кожного рілса агент питає, як зайшло. Кажеш покази й утримання — він
пише це в `profiles/user.json` і міняє налаштування:

| Що бачить | Що робить |
|---|---|
| Рілс просів проти сусідів | Підозрює хук і плитку профілю |
| Утримання падає в перші 3 с | Хук — підпис, а не заява. Переписує |
| Утримання спадає рівно | Ріже паузи агресивніше |
| У коментарях питають, що сказано | Збільшує субтитри або сповільнює |

Через кілька рілсів він знає твій темп, твої кольори і твої слова, які Whisper
завжди чує неправильно.
